# BedrockPy 기본 샘플 프로젝트

VS Code에서 이 폴더 자체를 열고 `pack.bpy` 또는 `main.bpy`를 연 다음 오른쪽 위의 컴파일 아이콘을 누르세요.

- `pack.bpy`: 팩과 출력 파일 설정
- `main.bpy`: 변수, 초기화, 틱 실행 코드
- `functions/`: 기능별 함수
- `sounds/`: 커스텀 사운드 원본
- `assets/`: 팩 아이콘 등의 원본
- `structures/`: 3D 편집용 `.bpstructure`
- `build/`: 컴파일할 때 자동 생성되는 결과물
- `.bedrockpy/`: 자동 버전 기록

생성된 `.mcpack` 또는 `.mcaddon`을 열면 Minecraft Bedrock Edition으로 가져올 수 있습니다.
